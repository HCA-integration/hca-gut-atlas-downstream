# ARBOL assets for Figure 2

Post-CAP dendrogram SVGs and the v1 taxonomy graph used by
`analyses/fig2_label_set` overlay renderers.

Tree construction is the published
[ARBOL](https://github.com/jo-m-lab/ARBOL) package. Install that
repository to rebuild the trees; these files are the frozen Fig. 2
overlays so the sidecar heatmaps can be re-rendered without rerunning
ARBOL.
