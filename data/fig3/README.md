# Figure 3b published effect sizes

`celltype_metadata_sensitivity_top2.csv` is the table that produced the
Figure 3b heatmap numbers in the submitted manuscript (S3 fibroblasts
radial 0.562, PAC endothelial radial 0.453, γδ T cells age 0.360,
colonocyte progenitors preservation 0.285).

The estimator is one-way ANOVA R² / η² of within-lineage CLR on each
covariate (intercept-only reduced model). The manuscript labels these
values ω²; they are partial R² vs intercept. The segment-stratified
ω² tables in `data/composition/covariate_audit/` are a later audit and
do not reproduce those four headline numbers.

Copied from the figure-production folder
`publication2026/fig_sampling_depth_radial/data/`.
