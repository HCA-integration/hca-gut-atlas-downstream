# Figure 4 b/e — mapping and enrichment analysis using Milo

Mapping was done in a two step approach first using the scANVI model of the full HGCA to obtain lineage labels followed by per lineage cell type label transfer.

Enriched cell populations in inflammation were calculated based on the shared embedding of the Taurus data subset using Milo.

The mapping was done following `fig4be_mapping_milo/src/b_mapping_scRNA_data_label_transfer.ipynb`.
The enrichment analysis is described in `fig4be_mapping_milo/src/e_identify_disease_populations.ipynb`
