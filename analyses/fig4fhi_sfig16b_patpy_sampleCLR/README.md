# Figure 4 f/h/i & supplementary figure 16b — Sample embedding using patpy and sampleCLR

The majority of this analysis was done using patpy and sampleCLR. The latter is a not yet published method to obtain sample or patient representations that can include batch correction and fine-tuning for a specific variable of interest.

The sampleCLR codebase will be published the latest with this manuscript.

The analysis for HGCA is shown in `fig4fhi_sfig16b_patpy_sampleCLR/src/sample_representation.ipynb` and input is the Taurus data that was mapped to the HGCA in `fig4be_mapping_milo/src/b_mapping_scRNA_data_label_transfer.ipynb`.
